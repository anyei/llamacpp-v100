Launch a model

Pick a model, pick how to run it, launch. The wizard reads your hardware and the fleet, and pre-selects the best route.
Entry point: one compose file, three variables. Everything else is decided here.
llama-server --models-dir /models --host 0.0.0.0 --port 8080 # router mode = no -m
Started with no model, llama-server runs as a router: this page reads the models dir, and Launch spawns a child server with the flags above overlaid on the model preset. Speeds marked "measured" come from sweeps.json in the models dir when present.
